# ESP32 桌邊藍牙控制器

ESP32-C3 核心板 + Display-Keypad 擴充板(0.96" 160×80 螢幕 + 五向鍵),橫向使用:**螢幕在左、按鍵在右**。
韌體 MicroPython,手機端是 Android 配套 App(Kotlin)。

```
deskctl/
├─ firmware/   板子上的 MicroPython 程式 + font12.bin(繁中點陣字型, 15,192 字)
├─ android/    手機端 App 原始碼(Android Studio / GitHub Actions 皆可打包)
├─ tools/      upload.sh / upload.bat(上傳韌體)、make_font.py(重製字型)、sim/(桌面模擬與測試)
└─ .github/workflows/build-apk.yml   推上 GitHub 就自動打包 APK
```

## 為什麼需要手機 App?

純 HID 藍牙(像藍牙鍵盤)只能「送按鍵」, 讀不到手機現在播什麼歌、播到幾秒、電量與音量。
要在螢幕顯示這些、而且做到精準 ±5 秒跳轉, 手機端必須有 App 讀取媒體工作階段並回報。
通訊用標準的 Nordic UART 服務(BLE), 訊息為一行一筆 JSON(見最後面)。

## 1. 接腳(已確認)

擴充板是**旋轉 180° 疊在核心板上**, 擴充板第 n 腳接到核心板第 33−n 腳(電源腳 1/2/7/8/15/16 與 SPI 腳 SDA/SCK 都能對上, 可交叉驗證):

| 功能 | 擴充板腳 | 核心板腳 | GPIO |
|---|---|---|---|
| 左 LKEY | 3 | 30 | 9 (BOOT 鍵) |
| 上 UPKEY | 4 | 29 | 8 |
| 中 CENTER | 5 | 28 | 4 |
| 下 DWKEY | 6 | 27 | 5 |
| 右 RKEY | 23 | 10 | 13 |
| 螢幕 BL / CS / DC / RES | 9 / 10 / 11 / 12 | 24 / 23 / 22 / 21 | 11 / 7 / 6 / 10 |
| 螢幕 SDA(MOSI) / SCL(SCK) | 13 / 14 | 20 / 19 | 3 / 2 |

要改腳位只要改 `firmware/config.py`。

**注意**
- **開機/重啟的瞬間不要按住「左」鍵**(GPIO9 = BOOT, 會進下載模式)。中央長按 5 秒重啟時放手即可。
- GPIO13 同時接板上 LED, 若「右」鍵偶爾誤判, 請告訴我, 可改軟體消除。
- GPIO11 在部分核心板是 flash 電源腳, 程式會自動嘗試; 失敗只代表無法關背光(常亮), 不影響使用。

## 2. 燒錄與上傳韌體(需要一台電腦做一次)

1. 下載 MicroPython 的 **ESP32_GENERIC_C3** 韌體(micropython.org/download/ESP32_GENERIC_C3/), 用 `esptool` 燒錄:
   `esptool.py --chip esp32c3 --port COM5 erase_flash` 然後 `esptool.py --chip esp32c3 --port COM5 --baud 460800 write_flash 0 ESP32_GENERIC_C3-xxxx.bin`
   (USB-C 接板上的 CH343P 那顆; Windows 需要 CH343 驅動)
2. `pip install mpremote`, 然後執行 `tools/upload.sh COM5`(Windows 用 `tools\upload.bat COM5`), 會把 `firmware/` 全部傳上去並重啟。
3. 第一次開機會出現**螢幕校正畫面**: 上=轉方向、下=反相、左=RGB/BGR 色序, 調到「文字正、按鍵在右、R/G/B 色塊顏色對」後按中央儲存。之後可在 目錄→快捷設定→螢幕方向校正 重做。

## 3. 手機 App(Android 8.0+)

**方法 A:不用裝 Android Studio**
1. 把整個 `deskctl` 資料夾推到你自己的 GitHub repo(私人的也行)。
2. 到 repo 的 Actions → Build APK → Run workflow, 完成後下載 artifact 裡的 `app-debug.apk`, 傳到手機安裝。

**方法 B:** 用 Android Studio 開 `android/` 資料夾, Build → Build APK。

首次設定(App 裡有 ①~④ 按鈕依序做):
1. ① 授權藍牙與通知。
2. ② 開啟「通知存取」並勾選「桌邊控制器」(這是 Android 讀取其他 App 歌名/進度的唯一合法管道)。Android 13+ 若灰色不能勾: 先按 ②-1 進 App 資訊 → 右上 ⋮ → 允許受限設定。
3. ③ 啟動。板子要先通電; App 會自動搜尋 `DeskCtl` 並記住, 之後斷線會自動重連, 手機重開機也會自動啟動(啟動過一次後)。
4. ④ 把電池設定改成「不受限制」, 避免系統在背景殺掉服務。

連上後右上角藍牙圖示變**綠色**, 首頁時間會自動校準。

## 4. 操作總表

手勢: **短按** / **雙擊** / **長按**(>0.6 秒) / **超長按**(5 秒)

### 全域
| 操作 | 功能 |
|---|---|
| 中央長按 | 開啟目錄(目錄中再長按 = 回原頁) |
| 中央連按 3 下 | 切回上一個頁面(來回切換, 不用進目錄) |
| 中央長按 5 秒 | **重啟整台裝置**(按住 1.8 秒後螢幕顯示倒數) |
| 方向鍵長按 5 秒 | **該頁重設 / 重新同步**(首頁、音樂=向手機重新要資料; 碼表=歸零; 遊戲=重新開始) |
| 左 / 右 短按 | 非音樂頁: 依「快捷清單」切換前/後一頁(首頁→右→碼表) |

### 目錄
上下選擇 · 中央進入 · **右鍵 = 加入/移出★快捷清單** · 左鍵返回。項目: 首頁、碼表、音樂、遊戲、說明書、快捷設定。

### 首頁
時間、日期、藍牙狀態、手機電量(含充電)、正在播放的歌。時間由手機校準。

### 碼表(背景持續計時, 計時中所有頁面右上角都有碼表圖示)
中央 開始/暫停 · 上 記圈 · 下 重設(需先暫停) · 下雙擊 隨時強制重設

### 音樂
| 操作 | 功能 |
|---|---|
| 中央短按 | 播放 / 暫停 |
| **中央雙擊** | 靜音 / 取消靜音(長按已留給目錄) |
| 右短按 / 左短按 | 快轉 +5 秒 / 倒轉 −5 秒 |
| 右雙擊 / 左雙擊 | 下一首 / 上一首 |
| 右 / 左 長按不放 | 連續跳轉 |
| 上 / 下 短按(可按住) | 音量 + / − 一格 |
| 上雙擊 | 隨機播放 開/關 |
| 下雙擊 | 循環模式: 不循環 → 清單循環 → 單曲循環 |

螢幕顯示: 歌名(太長會捲動)、歌手·專輯、進度條、目前/總時間、控制與隨機/循環狀態、音量、輸出裝置圖示(🎧 綠=藍牙耳機、藍=有線、📱=手機喇叭)、右上角時間。
(跳轉秒數、音量步進可在快捷設定調整)

### 遊戲
清單上下選、中央開始; 遊戲中**中央雙擊回清單**。
- 貪吃蛇: 方向鍵轉彎, 穿牆, 中央暫停, 越吃越快
- 1A2B: 左右選位、上下改數字(可按住)、中央送出
- 骰子猜大小: 上 押大(11–17)、下 押小(4–10)、左右調下注; 豹子通殺

### 說明書
上下翻頁(12 頁, 含按鍵位置圖解)。

### 快捷設定
時間制 12/24 · 首頁顯示秒 · 自動熄屏 · 跳轉秒數 · 音量步進 · 重新連線藍牙 · 螢幕方向校正 · 還原設定

## 5. 新增功能區/遊戲
1. 在 `firmware/` 新增 `g_xxx.py`, 寫一個繼承 `app.Page` 的類別(可參考 `g_dice.py`, 約 100 行)。
2. 在 `firmware/registry.py` 的 `PAGES` 加一行 `("id", "名稱", "g_xxx", "類別名", "game")`(群組 `main` 會出現在目錄, `game` 出現在遊戲清單)。
3. 用 `tools/upload.sh` 上傳。

## 6. 已知限制(請先知道)
- **我無法在實體板子與手機上測試**。韌體的畫面排版、手勢、頁面邏輯與藍牙封包處理都在桌面模擬器驗證過(`tools/sim/test_all.py`、`test_ble.py` 與畫面截圖), 但 ST7735 的顯示方向/色序、GPIO13 與 LED 共用、Android App 的編譯與實機行為都沒有實測。Android 專案在我的環境無法連到 Google 的套件庫所以**未編譯過**, 第一次打包若出現編譯錯誤請把錯誤訊息貼給我。
- 隨機/循環模式是否生效取決於音樂 App 是否開放(本地播放器多半支援, Spotify、YouTube Music 可能忽略); 無法讀回時, 螢幕顯示的是裝置自己記的狀態。
- 沒有媒體工作階段(沒開任何音樂 App)時, 播放/下一首會改送系統媒體鍵。
- 連線沒有配對密碼, 範圍內的其他 BLE 裝置理論上也能連上控制音量; 只連一台時別人連不進來。
- 手機端同時只追蹤一個音樂 App(優先「正在播放」的)。

## 7. 通訊協定(供除錯)
UUID 與 Nordic UART 相同(可用 nRF Connect 看): Service `6E400001-…`; 手機→板子寫入 `…0002`; 板子→手機通知 `…0003`; 每行一筆 JSON、以 `\n` 結尾。
- 手機→板子: `{"k":"time","t":unix秒,"z":時區分鐘}` · `{"k":"batt","p":83,"ch":1}` · `{"k":"track","t":歌名,"a":歌手,"b":專輯,"d":毫秒,"app":App名}` · `{"k":"play","s":0停/1播/2暫,"p":位置毫秒,"v":速度×100}` · `{"k":"vol","v":9,"m":15,"mu":0}` · `{"k":"route","r":"bt|wired|spk","n":名稱}` · `{"k":"mode","sh":0/1,"rp":0/1/2}` · `{"k":"ping"}`
- 板子→手機: `{"c":"pp"|"next"|"prev"|"mute"|"sync"|"pong"}` · `{"c":"seek","d":±毫秒}` · `{"c":"vol","d":±格}` · `{"c":"shuffle","v":0/1}` · `{"c":"repeat","v":0/1/2}`

## 8. 疑難排解
| 現象 | 處理 |
|---|---|
| 畫面全黑 | 確認背光(GPIO11); 到校正畫面試「上」換方向、「下」反相 |
| 畫面鏡像/顛倒 | 目錄→快捷設定→螢幕方向校正, 按「上」直到正確 |
| 紅藍顏色反了 | 校正畫面按「左」切換 RGB/BGR |
| 畫面偏移/邊緣有雜點 | `config.py` 的 `X_OFF` / `Y_OFF`(橫向預設 1 / 26) |
| 開機後出現錯誤文字 | 8 秒後會自動重啟; 用 `mpremote` 連線看完整錯誤訊息 |
| 圖示一直是灰色 | 手機 App 沒啟動 / 藍牙沒開 / 板子沒通電; 黃色 = 已連上但 App 沒回應(重新按③) |
| 沒有歌名 | 沒開「通知存取」, 或沒有任何音樂 App 在播放 |
| 右鍵不靈 | GPIO13 與 LED 共用, 回報我 |
